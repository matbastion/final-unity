# Final Unity – iPad-Starter

Web-App, die das DOS-Spiel *Star Trek: The Next Generation – A Final Unity* (1995) auf dem iPad startet:
Icon auf dem Home-Bildschirm, Vollbild, Touch-Steuerung, offline, Spielstände bleiben erhalten.

**Dieses Repository enthält keine Spieldaten.** Die Spieldatei (eigene Kopie) wird beim ersten Start
aus der Dateien-App ausgewählt und nur im privaten Speicher der App auf dem Gerät abgelegt.

Emulator: [js-dos / emulators](https://github.com/caiiiycuk/js-dos) (GPL-2.0, siehe `LICENSE-js-dos.txt`),
`wdosbox.js` ist um einen Lader ergänzt, der das CD-Image stückweise aus dem Gerätespeicher liest.

Steuerung: Tippen = Linksklick · lang drücken oder mit zwei Fingern tippen = Rechtsklick ·
ziehen = Maus mit gedrückter Taste · Menü oben rechts: Esc, Enter, Leertaste, Tastatur, Ton.
